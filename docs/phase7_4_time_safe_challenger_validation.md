# Phase 7.4 — Time-Safe Challenger Validation

## Goal

Make the first Phase-7 challenger evaluation genuinely time-safe: correlated
candidates from the same market event must stay together, every split must have
enough independent market events, and the final test set must remain untouched
until a challenger has already been selected using training/validation evidence.

## Independent-event split

Phase-7 automatic training now groups rows by `market_event_id` before the
chronological 70/15/15 split. All candidates generated by the same market event
therefore remain in exactly one of train, validation, or test. Existing label
window purging and embargo rules remain active.

The production cohort must satisfy the existing reliable-evaluation evidence
floors: at least 50 independent train events and at least 20 independent events
in each holdout split after purge/embargo. If those conditions are not met, the
auto trainer reports `WAITING_FOR_COHORT`; it does not register a failed model.

## Untouched-test policy

Baseline and ensemble candidates are trained using only train data and are
compared using only validation metrics. During that stage they are not given a
test-set path.

Only after the validation winner is frozen is the selected artifact evaluated
once against the test set. Rejected candidates never receive test metrics. The
test file is SHA-256 fingerprinted before and after final evaluation and training
fails closed if it changes.

Artifacts and reports explicitly record:

- `selected_using_test_data = false`;
- `test_set_policy = SEALED_UNTIL_FINAL_CANDIDATE_SELECTED`;
- independent market-event counts for train/validation/test; and
- proof that the test split checksum did not change.

## Authority boundary

Phase 7.4 remains offline/shadow learning work only. It does not change the
current rules champion, candidate selection, paper authority, real-order
authority, Execution risk, leverage, stops, or position management.

## Acceptance

Phase 7.4 code is accepted when:

1. the full regression suite passes;
2. market-event groups cannot cross split boundaries;
3. incomplete independent-event cohorts wait instead of training;
4. baseline/ensemble selection succeeds without access to the test file;
5. only the validation-selected winner is evaluated on the untouched test set;
6. Observation remains READY with order authority NONE; and
7. the auto trainer remains `WAITING_FOR_DATA` or `WAITING_FOR_COHORT` until the
   post-Phase-7.3 trustworthy cohort reaches the configured evidence floors.
