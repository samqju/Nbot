## 1. Owner-facing summary

We found useful parts in the older NBOT code: all original 24 detector hypotheses, source-validity and candle checks, bounded source buffering, compressed evidence segments, chronological price-path replay, economics validation, and some locked paper/risk controls. Much of this has offline regression fixtures. None of it is automatically approved as V5.1 code or as genuine scientific market evidence.

Old V5's hard 50-market and 100-direction-record design is not the current target. Build up to 100 **lightweight** observation markets, select up to 20 **deep original-source** markets including BTC, and use a **rolling maximum of 40 active** coin-direction virtual experiments. There must never be a forced trade. The old first-paper engine requires *two* models; V5.1 must later support an independently authorized qualified **Champion-only** paper phase before Challenger competition. Real trading remains a separate, locked release.

**G0-01 decision:** Keep a clean foundation; treat every old component as a separately inspectable candidate, never copy directories. Historical source branches, data and tests are preserved unchanged. The recommendations below are design disposition, NOT approval to copy or release. No model profitability is asserted.
